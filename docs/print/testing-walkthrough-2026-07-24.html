My Nail Connection 3.0 · Phone sign-in cutover

Testing Walkthrough

Anne + Leslie · July 24, 2026 · mynailconnection.com/v3/app

Before Leslie arrives Anne only

Run sql/phone-auth-normalize-existing-phones.sql in the Supabase SQL Editor. Required first. Without it, Leslie and all 27 existing techs look like brand-new users when they sign in by phone, and every test below fails in a confusing way.
Supabase → Auth → Email → turn Confirm email OFF for the testing window. Kills the email rate limit while testing.
Optional: review, then run sql/cleanup-anne-accounts.sql to clear the junk test accounts. Deletes are permanent, read the list it targets first.
Have ready: Leslie's phone, your phone, and one number that has never been in MNC (for the fresh-client test).

1. Leslie signs in by phone The big one

App → sign in → enter her mobile → Text me a code → the text arrives.
Enter the 6-digit code → Verify → she lands on her own tech dashboard.
Her profile is intact: photos, services, hours, bio. This proves an existing tech survives the cutover. If she looks like a new user, stop, the normalize SQL has not taken effect.

2. Sign out, sign back in

Sign out from the tech dashboard (the button is new, confirm it is there and works).
Sign back in with the same phone number. She should be recognized as returning, straight back to her dashboard, not pushed through signup again.

3. Brand-new client signup

Using the never-used number: sign up as a client. Phone and code only, no email should ever be asked of a client.
Sign out, sign back in with that number. Returning-user recognition for a fresh account.

4. New tech signup

Sign up as a tech: phone plus the optional email field. Confirm email is truly optional and nothing blocks on it.

5. The old email door

On the phone screen, tap "Have an email login? Use that instead" and sign in with an email account. The fallback has to keep working for anyone attached to their email login.

6. Contact the developer

Send a test message through the contact form; Anne confirms the email lands in her inbox.

7. If time allows, the money paths

As the test client, book an appointment with Leslie, confirm it appears on both sides.
As Leslie, upload a photo. Storage writes now require being signed in. If upload fails, this policy change is the first thing to check, not a dead end.
Expect a few leftovers. Some screens may still assume everyone has an email. That is normal for today. Nothing needs solving in the room, just capture the screen name and what it said below, each one is a fast fix afterward.
